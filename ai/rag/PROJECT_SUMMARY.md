# RAG API 项目分析与注释总结

## 项目概述

本项目是一个基于 FastAPI 的 RAG（检索增强生成）API 系统，专门用于文档索引和检索。系统集成了 Langchain 和多种向量数据库，主要为 LibreChat 提供文档处理服务，但也可用于其他基于文件 ID 的应用场景。

### 2. 代码注释添加 ✅

为以下核心文件添加了详细的中文注释：

#### 主要文件
- **main.py**: 应用入口，生命周期管理，中间件配置
- **app/config.py**: 配置管理，环境变量，嵌入模型初始化
- **app/models.py**: 数据模型定义，请求响应结构
- **app/middleware.py**: JWT 认证中间件
- **app/constants.py**: 常量和错误消息定义

#### 服务层
- **app/services/database.py**: PostgreSQL 连接池管理
- **app/services/mongo_client.py**: MongoDB 客户端服务
- **app/services/vector_store/factory.py**: 向量存储工厂
- **app/services/vector_store/async_pg_vector.py**: 异步 PostgreSQL 向量存储

#### 工具层
- **app/utils/document_loader.py**: 文档加载器，支持多种文件格式
- **app/utils/health.py**: 健康检查工具
